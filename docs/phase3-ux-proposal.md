# Phase 3 UX 제안: 구현 전 검토안

Android/iOS를 우선합니다. 아래는 화면 코드 변경 전의 정보 구조와 저충실도 안입니다. 웹 지도는 안내 화면이며 네이티브 기능과 같은 경험을 약속하지 않습니다.

## 정보 구조

| 화면 | 첫 정보 | 주요 동작 | 보조 정보 |
| --- | --- | --- | --- |
| 홈 | 오늘 기록한 개비, 기록 시각, 동기화 상태 | 빠른 기록, 갈망 대처 | 진행 중 목표 1개 |
| 기록 | 선택일 기록과 합계 | 추가·수정·삭제 | 날짜 이동, 메모·유발 요인 |
| 목표 | 계산 근거가 있는 진행률과 기간 | 목표 선택·완료 | 계산 불가 기존 목표는 수동 표시 |
| 통계 | 기록된 기간·총량·추세 | 기간 전환 | 데이터 없는 날의 의미 설명 |
| 지도 | 내 위치·구역·권한 상태 | 구역 조회·추가 | 위치 정확도와 자동 기록 상태 |
| 설정 | 계정·동기화·권한 상태 | 재시도, 기존 기록 가져오기 | 언어·테마·알림·감지 설정 |

## 홈 우선순위 비교

| 후보 | 필요성 | 첫 화면 배치 |
| --- | --- | --- |
| 핵심 지표 | 사용자가 현재 기록과 누락 가능성을 즉시 확인 | 최상단, 기록된 사실만 표시 |
| 빠른 기록 | 핵심 행동이며 입력 시간을 줄임 | 지표 바로 아래 단일 버튼 |
| 갈망 대처 | 기록 외에도 즉시 도움을 받을 수 있음 | 빠른 기록 옆 또는 다음 줄 |
| 목표 진행 | 동기 부여에 유용하나 근거 없는 진행률은 위험 | 계산 가능한 목표 1개만 요약 |

절약액과 건강 회복 수치는 개인 입력값과 검증된 근거가 없으면 표시하지 않습니다. 위치 체류·오디오·웨어러블 신호는 흡연을 확정하지 않으며 자동 감지 결과를 사실처럼 표현하지 않습니다. 기록이 없는 날은 “흡연 기록이 없는 날”이라고 표시하고 금연 성공과 구분합니다.

## 언어·테마·접근성·권한

- 한국어/영어 문구는 같은 정보와 상태를 제공하고, 숫자·날짜는 선택 언어와 기기 시간대를 따릅니다. UTC 저장 시각은 보고서에서 로컬 날짜로 변환합니다.
- 밝은/어두운/기존 특수 테마에서 텍스트·상태 대비를 확인합니다. 색만으로 진행·오류를 전달하지 않습니다.
- 글자 확대 시 카드 높이와 버튼 줄바꿈을 허용하고 잘림 없이 스크롤할 수 있어야 합니다. 숫자·단위·상태를 스크린리더가 한 문장으로 읽도록 레이블을 붙입니다.
- 위치·알림·마이크 권한이 거부되면 빈 지도나 무반응 버튼 대신 기능 상태, 직접 기록 경로, 기기 설정으로 이동하는 방법을 안내합니다. 권한 재요청은 사용자가 관련 기능을 켤 때만 합니다.
- 동기화 대기·실패·충돌을 눈에 띄게 표시하고 로컬 기록이 유지되었는지 알려줍니다. 계정 삭제는 서버 확인 뒤에만 완료로 표시합니다.

## Phase 3 제출 항목

- **A. 변경 파일과 이유:** 이 제안 문서만 추가했습니다. 화면 구현 전에 정보 구조와 상태별 문구를 검토하기 위한 것입니다.
- **B. 호환성과 롤백:** 앱 코드와 저장 데이터는 변경하지 않았습니다. 문서 커밋만 되돌릴 수 있습니다.
- **C. 검증:** Phase 2 종료 시 30개 테스트, typecheck, lint, 웹·Android·iOS export가 통과했습니다. 이 문서의 화면안은 사용성 검증을 거치지 않았습니다.
- **D. 성능:** 제안 문서라 변경 전후 성능 수치가 없습니다. 구현 시 화면 렌더 p50/p95, 기록 완료 시간, 목록 스크롤, 위치·지도 요청을 같은 조건에서 측정합니다.
- **E. Claude 리뷰:** 연결 수단이 없어 읽기 전용 리뷰와 지적 반영은 아직 수행하지 못했습니다.
- **F. 남은 위험과 진입 여부:** 실기기 권한·접근성·데이터 누락 상태 검증과 사용자 평가가 필요합니다. 이 문서를 기준으로 세부 디자인을 검토할 수 있으나 화면 구현은 아직 시작하지 않았습니다.
